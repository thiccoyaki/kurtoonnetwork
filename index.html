Narration cleaner

A Python and ffmpeg app that strips dead air from AI voiceovers and tightens the pacing, so narration is ready to edit in one pass.

  • Silence detection with configurable minimum pause and target pause
  • Speed and pitch-shift controls, with ElevenLabs model support
  • Chunked filtergraph, stress-tested on files with 2,000 pauses
  • Command line, desktop interface and a packaged .exe

Python, ffmpeg, ElevenLabs

Automated content pipeline

A hybrid AI and CI pipeline that turns competitor outliers into a daily, review-ready batch of scripts and voiceovers.

  • Outliers found with vidIQ, then fact-checked with web search
  • Scripts checked in code against exact character targets
  • GitHub Actions runs text-to-speech, the cleaner and the Google Drive upload
  • A log that prevents repeat topics, and one Discord link a day

GitHub Actions, Claude, Drive API, Discord webhooks

YouTube revenue tracker

A locally hosted Streamlit dashboard that tracks revenue, costs and profit across my channels with live analytics.

  • YouTube Analytics API over OAuth, one connection per channel
  • Cost rules per channel and five financial indicators
  • SQLite storage and a dashboard in several tabs
  • Claude API built in for ideas and first-draft scripts

Streamlit, OAuth 2.0, YouTube Analytics API, SQLite

Niche hunter

YouTube Data API v3, Python, Plotly
