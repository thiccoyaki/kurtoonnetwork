# Kurt Agravante — Portfolio

Dual-mode portfolio site. Toggle between **Analytical** (data, programming, tooling) and **Creative** (YouTube growth, marketing) at the top of the page, or press `M`.

## Files
- `index.html` — the whole site (HTML, CSS, JS in one file)
- `analytics-2025.png` — YouTube analytics screenshot shown on the Creative side

## Hosting
Served with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
