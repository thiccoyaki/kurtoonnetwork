# Kurt Agravante — Portfolio

Dual-mode portfolio. Switch between **Analytical** (automation, data, tooling) and **Creative** (YouTube growth, storytelling) in the top bar, or press `M`. The choice is remembered per visitor.

## Files
- `index.html` — the whole site (HTML, CSS, JS in one file)
- `analytics-2025.png`, `analytics-2026.png` — YouTube Studio screenshots used as proof
- `fonts/` — Switzer (Indian Type Foundry, free licence via Fontshare), self-hosted

## Hosting
Served with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
